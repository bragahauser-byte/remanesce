# Remanesce

**O que permanece, renasce.**

Site e e-commerce da Remanesce, marca de denim autoral, e da coleção **O Renascer da Permanência**,
inspirada na pinha da araucária. Projeto acadêmico.

## Status
Repositório inicial com briefing, conceito, imagens do line-up e a especificação completa para o
desenvolvimento com Claude Code. O app Next.js será criado a partir de `PROMPT.md`.

## Estrutura atual
```
PROMPT.md            especificação completa (cole no Claude Code)
CLAUDE.md            contexto permanente para o Claude Code
docs/briefing.md     briefing da cliente e entregáveis
docs/conceito.md     conceito de criação (texto da equipe)
public/images/lineup line-up original (frente e costas)
public/images/looks  um arquivo por look, frente e costas
```

## Como começar
1. Abra o terminal nesta pasta.
2. Rode `claude`.
3. Cole o conteúdo de `PROMPT.md`.

## Stack prevista
Next.js · TypeScript · Tailwind CSS · GSAP + Lenis · Zustand · React Hook Form + Zod · Vercel
